# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2024-12-19

### Added
- Initial release of NotePodcast web application
- Podcast playback functionality with Apple-style UI
- AI-powered summaries with personalized titles using ZhipuAI (GLM-4)
- Personal notes management with voice input support
- Transcript display with multi-language translation
- Support for multiple podcast URL types:
  - RSS feed URLs
  - Xiaoyuzhoufm.com episode URLs
  - Direct audio file URLs
- Shownotes parsing with intro section extraction
- Time-point based navigation in summaries and notes
- Audio player with speed control and progress tracking

### Technical Stack
- React with TypeScript
- Vite for build tooling
- ZhipuAI API integration (GLM-4 for summaries, GLM-3-turbo for translations)
- localStorage for notes persistence
- CSS Modules with Apple-style design system

### Features
- **Audio Player**: Play/pause, speed adjustment (0.5x-2.0x), draggable progress bar
- **AI Summaries**: Three dynamic summary tabs with personalized titles generated by LLM
- **Original Podcast Notes**: Parsed shownotes with time-point segments
- **Personal Notes**: Add, delete, sort notes with voice input (Web Speech API)
- **Transcripts**: Full transcript display with translation support (Chinese, English, Japanese, Korean, Spanish, French)
- **Responsive Design**: Optimized for desktop (1920x1080, compatible with 1366x768+)
- **Apple-Style UI**: Clean, minimalist interface with unified rounded corners and color scheme

### Known Limitations
- ZhipuAI does not provide audio transcription API (transcript generation disabled)
- Voice input uses Web Speech API as fallback (browser compatibility required)
- CORS limitations may affect direct access to some podcast feeds
